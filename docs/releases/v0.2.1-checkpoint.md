## Planning item — emergency/dashboard (not started)

Re-enable requires real behavior, not audit stubs:

1. **Circuit break** — a real breaker that can actually disable a
   capability/skill: persisted breaker state, disable + re-enable with
   proof of effect (the disabled path demonstrably refuses), audit
   trail. MVP shape: per-skill breaker in the execution plane, not a
   facade over the route table.
2. **Session termination** — real kill of a running agent session
   (SIGTERM → grace → SIGKILL), persisted session state, proof of
   termination (process gone + state terminal) before ok:true.
3. **Dashboards** — real queries over the audit log and stores
   (agent activity, token trends, run stats) with data, not literal
   SQL placeholders.

Gate: each endpoint performs and proves its action (honest-success
rule), handler-level tests + live e2e, fresh-context review.
