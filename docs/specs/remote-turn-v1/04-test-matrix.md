## Validation order

1. Core pure schema/state/token/receipt tests.
2. Postgres transaction, concurrency, restart, and cross-instance tests.
3. Fake runtime and fake attestor contract tests with adversarial messages.
4. Private-layer image/attestor/egress/termination tests.
5. One-scope real canary and rollback drill.
6. Targeted typecheck/lint and an independent fresh-context security/code review.

No test is waived because a broader existing suite is green. No canary starts while any RTH criterion lacks its negative test.
