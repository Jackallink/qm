# Remote Turn v1 — Protocol Schema (Normative)

This file is the single normative source for every signed artifact in the Remote Turn protocol: turn/abort tokens, pre-claim attestation, start proof, termination proof, receipts, and usage statements. Round 2 describes behavior; this file fixes byte-level contracts. Every artifact is a strict JSON Schema with `additionalProperties: false` — an unknown field is a rejection, never an ignore. Schema versions are bound to `binding.protocolVersion`; a schema change increments the version and new admissions use the new version only.

## Signing envelope

All three attestation artifacts and both receipts use JWS compact serialization (jose `CompactSign`): `base64url(header) || "." || base64url(payload) || "." || base64url(signature)`.

- Algorithm: Ed25519 (EdDSA). `alg` is a closed single value within a protocol version; an artifact signed with any other algorithm is rejected.
- Header: `{ "alg": "EdDSA", "kid": "<key id from the binding's pinned key set>" }`.
- Content-address digests (release, input, envelope, execution lease, termination evidence) are SHA-256 hex, 64 lowercase characters.
- JTI, nonce, and lease values are generated by a CSPRNG with at least 128 bits of entropy; only their SHA-256 hashes are stored by core.

## Common field definitions

| Field | Type | Meaning |
| --- | --- | --- |
| `remoteTurnId` | string (UUID) | The RemoteTurn record id. |
| `bindingVersion` | positive integer | Version of the binding snapshot used for this turn. |
| `turnJtiHash` | sha256-hex | Hash of the turn JTI. |
| `abortJtiHash` | sha256-hex | Hash of the abort JTI. |
| `attestationNonceHash` | sha256-hex | Hash of the attestation nonce. |
| `executionLeaseHash` | sha256-hex | Hash of the execution lease. |
| `inputDigest` | sha256-hex | Digest of the current user plain text. |
| `historyDigest` | sha256-hex | Digest of the canonical serialization of the up-to-eight history messages. |
| `envelopeDigest` | sha256-hex | `SHA-256` over the 8 fields `remoteTurnId, bindingVersion, conversationKey, scopeId, qmSessionId, coreRunId, inputDigest, historyDigest` in this order, each field serialized as a length-prefixed frame: `uint32BE(fieldLen) || utf8(field)` concatenated in order. `historyDigest` is `SHA-256` over per-message frames `uint32BE(roleLen) || utf8(role) || uint32BE(textLen) || utf8(text)` concatenated in message order. `inputDigest` is `SHA-256(utf8(text))`. Length-prefix framing removes any role/text boundary ambiguity; JSON key order and whitespace never enter the digest. |
| `releaseDigest` | sha256-hex | Digest of the immutable runtime release image. |
| `policyDigest` | sha256-hex | `SHA-256(policySnapshotHash \|\| networkPolicyId \|\| endpointAllowlist \|\| egressAudience)`; core compares it to the binding snapshot. |
| `sandboxId` | string | Attestor-assigned sandbox identity. |
| `workloadIdentity` | string | Attested workload identity inside the sandbox. |
| `networkPolicyId` | string | ID of the enforced non-bypassable network policy. |
| `endpointAllowlist` | array of strings | Exact model endpoint allowlist (URLs). |
| `egressAudience` | string | Opaque URN identity of the egress gateway. |
| `runtimeAudience` | string | Opaque URN such as `urn:qm:v1:runtime:<configuredOrgId>:<name>`; never an endpoint URL, never equal to `egressAudience`. |
| `kid` | string | Signing key id; must exist in the binding's pinned key set. Placement is per artifact: receipts carry it in the JWS header only; usage statements carry it in the payload; start/termination proofs use `attestorKid`; the pre-claim attestation's header `kid` is the only key reference. Each artifact's placement is fixed by its schema. |
| `iat` / `nbf` / `exp` | integer (Unix seconds) | Issued-at / not-before / expiry. `exp = iat + tokenTtlMs/1000`; skew (30s) applies to `nbf`/`iat` acceptance only and never extends `exp`. |

## Schema encoding

Each artifact below is a JSON Schema draft 2020-12 object. `"type": "object"`, `"additionalProperties": false`, and `"required"` list every mandatory field. `sha256-hex` means `pattern: "^[a-f0-9]{64}$"`. `uuid` means `pattern: "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$"`. A verifier rejects a payload that fails its schema before any signature or semantic check; a signer refuses to sign a payload that fails the schema.

## Turn token claims

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["kid", "iss", "aud", "iat", "nbf", "exp", "jti", "capability", "remoteTurnId", "bindingVersion", "conversationKey", "scopeId", "qmSessionId", "coreRunId", "inputDigest", "envelopeDigest", "protocolVersion"],
  "properties": {
    "kid": { "type": "string" },
    "iss": { "const": "urn:qm:core" },
    "aud": { "type": "string" },
    "iat": { "type": "integer" },
    "nbf": { "type": "integer" },
    "exp": { "type": "integer" },
    "jti": { "type": "string", "minLength": 16 },
    "capability": { "const": "turn" },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "bindingVersion": { "type": "integer", "minimum": 1 },
    "conversationKey": { "type": "string" },
    "scopeId": { "type": "string" },
    "qmSessionId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "coreRunId": { "type": "string" },
    "inputDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "envelopeDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "protocolVersion": { "type": "integer", "minimum": 1 }
  }
}
```

Verification: signature under a key in the binding's pinned verification key set; `kid` recorded; `aud` exact string equality with `binding.runtimeAudience`; `nbf <= now` (allowing 30s forward skew on `iat`/`nbf`); `now < exp`; `envelopeDigest` matches the persisted envelope; single consumption by JTI hash.

## Abort token claims

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["kid", "iss", "aud", "iat", "nbf", "exp", "jti", "capability", "remoteTurnId", "bindingVersion", "turnJtiHash", "protocolVersion"],
  "properties": {
    "kid": { "type": "string" },
    "iss": { "const": "urn:qm:core" },
    "aud": { "type": "string" },
    "iat": { "type": "integer" },
    "nbf": { "type": "integer" },
    "exp": { "type": "integer" },
    "jti": { "type": "string", "minLength": 16 },
    "capability": { "const": "abort" },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "bindingVersion": { "type": "integer", "minimum": 1 },
    "turnJtiHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "protocolVersion": { "type": "integer", "minimum": 1 }
  }
}
```

Verification: `capability === "abort"`; never grants `/turn`; before claim binds only `turnJtiHash`; after claim the lease-bound abort authority was minted atomically inside the claim transaction and the same token carries `executionLeaseHash` and `coreRunId`, which verification then requires; single consumption by abort JTI hash. The post-claim form is the same JWT whose verification switches to the lease-bound authority.

Post-claim abort token claims (the pre-claim schema extended by the claim transaction):

```json
{
  "executionLeaseHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
  "coreRunId": { "type": "string" }
}
```

Both fields are absent before claim and required after claim; a verifier rejects an abort token that omits them once the RemoteTurn is past `claimed`.

## Pre-claim attestation (attestor-signed)

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["artifact", "schemaVersion", "remoteTurnId", "bindingVersion", "turnJtiHash", "attestationNonceHash", "intendedWorkloadIdentity", "plannedSandboxId", "releaseDigest", "isolationMode", "policyDigest", "networkPolicyId", "endpointAllowlist", "egressAudience", "expiry", "singleUse"],
  "properties": {
    "artifact": { "const": "pre_claim_attestation" },
    "schemaVersion": { "type": "integer", "minimum": 1 },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "bindingVersion": { "type": "integer", "minimum": 1 },
    "turnJtiHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "attestationNonceHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "intendedWorkloadIdentity": { "type": "string" },
    "plannedSandboxId": { "type": "string" },
    "releaseDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "isolationMode": { "type": "string" },
    "policyDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "networkPolicyId": { "type": "string" },
    "endpointAllowlist": { "type": "array", "items": { "type": "string", "format": "uri" }, "minItems": 1 },
    "egressAudience": { "type": "string" },
    "expiry": { "type": "integer" },
    "singleUse": { "const": true }
  }
}
```

It contains no execution lease. The attestor verifies the core-signed turn token and persists `(attestationNonceHash, turnJtiHash)` single-use state before attesting. The sandbox must already exist with its isolation verified before this attestation is signed.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["artifact", "schemaVersion", "remoteTurnId", "bindingVersion", "turnJtiHash", "executionLeaseHash", "sandboxId", "workloadIdentity", "releaseDigest", "networkPolicyId", "egressTokenId", "startTime", "attestorKid"],
  "properties": {
    "artifact": { "const": "start_proof" },
    "schemaVersion": { "type": "integer", "minimum": 1 },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "bindingVersion": { "type": "integer", "minimum": 1 },
    "turnJtiHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "executionLeaseHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "sandboxId": { "type": "string" },
    "workloadIdentity": { "type": "string" },
    "releaseDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "networkPolicyId": { "type": "string" },
    "egressTokenId": { "type": "string" },
    "startTime": { "type": "integer" },
    "attestorKid": { "type": "string" }
  }
}
```

Core enforces `startProof.sandboxId === preClaim.plannedSandboxId` and `startProof.workloadIdentity === preClaim.intendedWorkloadIdentity`; mismatch parks the turn with `runtime_attestation_invalid`. The execution lease is delivered to the attestor directly by core over its mTLS interface, never relayed by the runtime.

```json

  "type": "object",
  "additionalProperties": false,
  "required": ["artifact", "schemaVersion", "remoteTurnId", "executionLeaseHash", "sandboxId", "exitResult", "egressRevocationAck", "egressTokenId", "timestamp", "attestorKid"],
  "properties": {
    "artifact": { "const": "termination_proof" },
    "schemaVersion": { "type": "integer", "minimum": 1 },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "executionLeaseHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "sandboxId": { "type": "string" },
    "exitResult": { "const": "deleted" },
    "egressRevocationAck": { "const": true },
    "egressTokenId": { "type": "string" },
    "timestamp": { "type": "integer" },
    "attestorKid": { "type": "string" }
  }

```

Trusted only because the attestor sits outside the runtime's trust boundary (hard invariant 4). A report signed by a component inside that boundary is treated as a runtime self-report and does not complete or cancel a turn.

## Receipt (runtime-signed with the binding's receipt key set)

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["artifact", "schemaVersion", "remoteTurnId", "bindingVersion", "executionLeaseHash", "inputDigest", "releaseDigest", "status", "reply", "outputBytes", "runtimeMs", "receivedAt"],
  "properties": {
    "artifact": { "const": "receipt" },
    "schemaVersion": { "type": "integer", "minimum": 1 },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "bindingVersion": { "type": "integer", "minimum": 1 },
    "executionLeaseHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "inputDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "releaseDigest": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "status": { "const": "completed" },
    "reply": { "type": "string", "maxLength": 16384 },
    "outputBytes": { "type": "integer", "minimum": 0, "maximum": 16384 },
    "runtimeMs": { "type": "integer", "minimum": 0, "maximum": 60000 },
    "receivedAt": { "type": "integer" }
  }
}
```

Validation: key set snapshotted at admission (`receiptKeySetVersion`); `kid` in that snapshot's `current ∪ overlap` set; signature, lease hash, input/release digest, status, and output/usage schema all match; `reply` within the output bound — `maxLength` counts code points, so the verifier additionally enforces the 16 KiB UTF-8 **byte** bound on `reply` and `outputBytes`; `format: "uri"` fields are asserted by the verifier, not just annotated. Rotation during execution never rejects a receipt signed under the old key.

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "additionalProperties": false,
  "required": ["artifact", "schemaVersion", "remoteTurnId", "executionLeaseHash", "workloadIdentity", "endpoint", "usage", "costUsd", "timestamp", "kid"],
  "properties": {
    "artifact": { "const": "usage_statement" },
    "schemaVersion": { "type": "integer", "minimum": 1 },
    "remoteTurnId": { "type": "string", "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" },
    "executionLeaseHash": { "type": "string", "pattern": "^[a-f0-9]{64}$" },
    "workloadIdentity": { "type": "string" },
    "endpoint": { "type": "string", "format": "uri" },
    "usage": {
      "type": "object",
      "additionalProperties": false,
      "required": ["inputTokens", "outputTokens"],
      "properties": {
        "inputTokens": { "type": "integer", "minimum": 0 },
        "outputTokens": { "type": "integer", "minimum": 0 }
      }
    },
    "costUsd": { "type": "number", "minimum": 0 },
    "timestamp": { "type": "integer" },
    "kid": { "type": "string" }
  }
}
```

Only a valid statement bound to the exact execution lease can release unused reservation; missing trusted usage charges the full reservation; invalid/mismatched metering parks the active turn.

## Key-set rotation rules

- Receipt and metering key sets are ordered entries `[{kid, publicKey, state: current|overlap, activatedAt, retiresAt}]`.
- At most one overlap entry exists at any time; the overlap lifetime is explicit (recommended at least `10 x tokenTtlMs`).
- Verification records the `kid` used; an unknown, retired, or mismatched key is a permanent rejection.
- Removal of an old key requires a binding version change.
- Each artifact's `alg` and `kid` set is closed within a protocol version; no mixing of algorithms per artifact.
