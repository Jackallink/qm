# Round 3 — 阶段门禁、错误处理与证据

## 所有阶段的共同 Gate

| Gate | 必需证据 | 失败时的处理 |
| --- | --- | --- |
| 需求与范围 | 业务需求覆盖、In/Out、外部依赖、owner、风险和回滚 | 返回 draft，不开始设计实现 |
| 设计走查 | 三轮 walkthrough、闭合状态/API 路径、错误契约 | 返回 walkthrough，修正未闭合路径 |
| TDD 启动 | AC 到正向/负向/恢复测试，先有红测试 | 不实现或不启用能力 |
| 实现验证 | durability、跨实例、重启、授权、隔离、失败与撤销证据 | 回到实现或设计，禁止 canary |
| 运行证明 | 私有层 contract proof、canary、回滚演练、runbook | 禁止扩大 scope 或对外宣称完成 |
| 独立审查 | 新鲜上下文安全/代码/文档审查 | 关闭审查发现后重跑相关门禁 |

## 阶段 Exit Gate

| 阶段 | Go 证据 | Stop 条件 |
| --- | --- | --- |
| F0 | 完整 legacy inventory；正常 QM turn 回归；每个遗留入口、配置、环境和存储选择均有不可达/拒绝测试 | 任一生产请求仍可选择或构造遗留 runtime、host launcher、假控制面或自动导入 |
| D0-L | 全容器 Core/Web/Admin/Portal/Postgres、loopback 端口、版本化本地 profile、non-purge 卷持久化、受限宿主验证器的真实文本模型、单服务恢复、secret 边界与 execute fail-closed 证据 | 将混合 dev-instance 当作全容器；端口暴露到非 loopback；未验证 execute/sandbox 被启用；把本机 Docker 成功当作 Portal 浏览器 E2E、生产、Kubernetes 或 F1 证明 |
| D0-T | 私有部署层逐项需求覆盖表；每项红线、必达运行形态、文档/业务范围、量化指标、owner、验收人、差异/豁免与失败策略均可追踪；目标数据库的一致性/锁/迁移/故障恢复 proof；目标部署、网络、架构、操作系统、许可、加密、地址/时间同步、高可用、存储和消息依赖的可行性证据 | 任一编号需求没有归属/验收路径；目标环境不能证明所需事务或隔离语义；以本机依赖或未批准替代方案作为生产结论 |
| G0 | 指定入口的服务端身份链；每次受保护调用的治理鉴权、审批、能力状态同步和 trace/error/result/audit 回执 contract tests；依赖失效时 fail-closed 测试 | 可由 cookie、header、环境变量、runtime 或浏览器伪造身份/授权；高风险、远程或外部动作在治理依赖故障时降级放行 |
| X0 | 参考 runtime 的固定 release/镜像、工作负载身份、attestation、非旁路 egress、短期令牌注入、终止、撤权、升级/回滚与目标环境 canary 演练 | 自报配置取代可信证明；宿主进程、共享密钥或直连网络可执行；终止或撤权不能证明生效 |
| F1 | D0-L/D0-T/G0/X0 全部通过；Remote Turn AC 全部通过；目标数据库上事务/重启/跨实例一致性测试；私有层 attestation、egress、termination 演练；限定 scope canary 成功、拒绝、重启、abort、rollback 的耐久 trace | 任一未证明 egress/termination/usage，重复 lease，跨 scope，或无证明的完成/取消 |
| C1 | 版本化定义/Release、ACL、quota、并发发布/停用/回滚与跨实例恢复测试；小范围 Release drill | 用内存作权威、浏览器直改策略、定义记录启动 host 进程，或 online/stopped 不对应真实状态 |
| C2 | 会话隔离、流和断连语义、并发输入、取消、重启恢复、历史可见性测试 | scope 共享状态、断连丢失/混淆状态，或流式结果越过授权/审计 |
| M1 | 服务端模型路由、QoS、密钥边界、用量/效果记录；用户/Agent/场景/权限隔离的上下文、记忆和工作区；召回、更新、过期、删除、审计和跨实例恢复测试 | 用户或 runtime 自选未授权模型；跨 scope/context/memory/workspace 泄露；零计量、无法删除或无审计的持久上下文 |
| A1 | capability/审批/产物/输入输出与数据安全/egress/密钥/删除/补偿的正负测试；私有覆盖表指定的文档或文件处理范围 canary；公开级组合定义仅在治理授权边界内的 contract test | 未授权工具调用、路径逃逸、提示注入导致越权、敏感数据异常外发、无账本外部副作用，或无法说明补偿 |
| T1 | durable task/子任务、结果验证、暂停/恢复/取消/接管、失败节点与有副作用恢复测试；action-class retry/degrade 表和人工接管 drill | 只读/已证明幂等之外的动作自动重试；不可逆动作无独立审批；结果验证仅信任 Agent 自述 |
| C3 | 消息与 job 的 durable outbox/inbox、签名/授权、幂等、DLQ、并发 worker、分区/失序/catch-up/循环/停止测试 | 将存储记录称为投递/执行，或使用内存 Map/cron 文本代替调度与恢复 |
| O1 | 逐目标真实急停、能力停用、令牌撤权、终端/工作负载停用、会话阻断、策略回滚与失败恢复；审计读取隔离、trace 关联、实时通知/运营分析、告警、备份/恢复、灰度/升级兼容；控制 API 错误语义和管理 UI 浏览器安全验证 | 控制请求返回成功而目标未动作，UI 绕过认证/审计，跨 scope 读写泄露，或控制/通知/分析链路无法还原目标结果 |
| X1 | F1 参考运行时之外的每个新增 adapter 的威胁模型、身份/attestation、隔离、egress、升级、撤权、审计、迁移和停止证据；限定 canary | adapter 可绕过统一入口/治理权威，设备/工作负载身份不可证明，或撤权无法实际生效 |
| B1 | 私有覆盖表每项均有 accepted 证据；合同指定的业务场景、文档/文件处理范围、必达运行形态、量化指标、端到端 trace、用户/运营评价、故障/回滚演练和验收人签核 | 仅有技术演示/API/页面，以任意场景或任意 adapter 替代指定范围，业务安全路径未验证，或量化指标没有定义分母/窗口/数据来源 |

## 统一异常原则

| 发现 | 立即动作 | 恢复条件 |
| --- | --- | --- |
| 跨 scope、跨会话或跨租户访问 | 停止扩大范围，禁用受影响 binding/Release，保留证据 | 根因修复、负向回归、独立复核通过 |
| 不确定的外部执行、重复动作或重复计费 | 停止自动重试，park 记录，撤销仍可撤销的权限 | 幂等/补偿/人工处置方案及恢复测试通过 |
| 没有证明的成功、取消、回滚或急停 | 标记操作未完成，不对用户/运营方返回成功 | 取得独立终止/撤权/目标结果证明 |
| 未授权 egress、密钥暴露或 adapter 身份异常 | 立即禁用 binding/adapter，撤销令牌，保全审计 | 隔离、凭证轮换、攻击路径回归与安全审查完成 |
| 审计、预算、持久化或治理授权不可用 | 拒绝新的高风险或远程执行，不降级为内存/直连模式 | 依赖恢复、事务/审计连续性验证完成 |

## 指标与运营验收

路线图不在上游重复组织专属数字，但私有覆盖表中的已批准量化目标均为硬约束。每一个准备验收的指标都必须有：

1. 业务目标和准确分母；
2. 适用 scope、时间窗口和排除条件；
3. 不可由 runtime 自报伪造的数据来源；
4. 告警阈值、责任人、升级路径和回滚触发条件；
5. canary 基线、容量评估和业务/运营签核。

建议从 F1 开始采集成功率、P50/P95 时延、拒绝/park 原因、预算保留与回滚时间；从 A1/T1 开始采集授权动作、审批、结果验证和补偿；从 O1/B1 以原始目标的统计口径验收覆盖率、可用性、端到端成功率和满意度。采集基线不得延后、稀释或替换已批准目标。

## Round-3 批准条件

路线图只有在每个阶段都有 Go/Stop 条件、证据类型、异常动作和下一阶段阻塞关系时才可作为排期依据。缺少 owner、外部依赖或可观测证据的阶段保持 proposed，不进入实现。
